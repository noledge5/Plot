# Plot

Lokale Rollenspiel-Engine für die eigene NAS: Erzählung über die OpenRouter-API,
mit eigenem System-Prompt, Charakterkarten, Beziehungsmechanik, dauerhaftem
Gedächtnis und Speicherslots. Ein Docker-Container, eine SQLite-Datei, erreichbar
von jedem Gerät.
